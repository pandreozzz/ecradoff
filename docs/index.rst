ecRadOff documentation
======================

ecRadOff is a framework for customizable and reproducible offline radiation calculations using ecRad as a radiative transfer engine. While all radiation calculations are performed by ecRad, ecRadOff acts as a wrapper that pre-processes model data input, produces several diagnostics needed by the radiation scheme and post-processes the ecRad output at the end of the calculations.
